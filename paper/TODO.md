## 🔴 CRITICAL — Must Fix Before Any Experimental Claims

### T-01 · Agent-name heuristic clamps must be removed or disclosed prominently

**File**: `rejector.js` lines 352–358

**Problem**: `U_sem` values are forcibly clamped per agent name *after* the weighted
combination, overriding the computed uncertainty signal:
- System Architect: `U ← clamp(U + 0.3, 0.45, 0.55)`
- Implementation agents: `U ← clamp(0.3 × U, 0.03, 0.20)`

**Consequence**: Any observed "strategic-to-implementation uncertainty gradient" is a
hard-coded artefact, not an emergent property of the uncertainty signals. The paper
currently notes this honestly, but all *experimental* results (once run) will be
invalidated by this if the clamps remain.

**Action required**:
1. Remove the clamps (or make them an explicitly evaluated ablation condition).
2. Re-run the full 500-episode simulation and check whether U_sem / U_ent / U_ref
   naturally stratify by agent type.
3. If the gradient does not emerge naturally, revise the claims accordingly.

### T-03 · Ground-truth labels are heuristic, not human-annotated

**File**: `environment.js` (random scenario label assignment)

**Problem**: Random scenario labels are generated by:
```js
y = (gravity > 0.3 && agreement < 0.7) || (gravity > 0.5 ? rng() > 0.5 : false)
```
This is not an independent ground-truth; it is a rule derived from the same
variables the gate uses. The gate is essentially evaluated against its own prior.

**Action required**:
1. Design a human annotation study: recruit at least 2 annotators; present each
   scenario description + I/R/P values; ask "Does this decision require human
   review? (Y/N)".
2. Compute Cohen's κ between annotators and between human labels and heuristic
   labels.
3. Use human labels as the reference for all published metrics.
4. Report the κ value in Section VIII.

### T-06 · Decision Gravity formula — product vs. geometric mean vs. weighted sum

**File**: `rejector.js` (`G = I × R × P`)

**Problem**: The plain product has a known fragility: `G = 0` if any factor is zero,
regardless of the other two. For example, a fully reversible but high-impact,
high-propagation decision receives `G = 0`.

**Reviewer suggestion**: Consider:
- Geometric mean: `G = (I · R · P)^(1/3)` — still zero when any factor is zero,
  but more balanced when all are non-zero.
- Weighted sum: `G = w_I·I + w_R·R + w_P·P` — never zero unless all factors are
  zero; loses the multiplicative "all must be high" semantics.

**Action required**:
1. Run the preset 20 scenarios with all three formulas.
2. Tabulate how often the formula changes the binary gate decision.
3. Report the chosen formula with justification.

**Action required (at minimum)**:
